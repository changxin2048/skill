# 手绘风 SVG 生成器 (Hand-Drawn SVG)

把结构化的框图（架构图 / 流程图 / 思维导图 / 系统图等）变成"像用马克笔在网格纸上手绘"的 SVG 矢量图。

## ⚠️ 路径说明（必读，先看这里再动手）

本 Skill 内所有相对路径（`references/sketch_recipe.md`、`scripts/render_preview.py`、`assets/`）**都相对于 Skill 资源目录**，不一定是当前工作目录！

- 资源目录 = 调用 `skill` 工具时返回的 `resourceBase.path`，

**禁止**把相对路径按当前工作目录解析（会报 not found）。用 `read` / `glob` / `bash` 访问上述文件时，一律拼上资源目录的绝对路径；调用渲染脚本同理（见工作流第 6 步）。

## 核心思路（先理解 Why）

手绘感 = **笔迹抖动 + 手写字体 + 纸张质感 + 不完美的线条**，四者缺一效果都不对。不要画完美直线、直角、正圆——所有"生硬感"都要靠滤镜和字形消除。结构内容由用户需求决定，风格统一由本 Skill 决定。

## 工作流

1. **解析需求**：确定图的类型、层/模块、连接关系、文案。布局与内容跟着用户需求走。
2. **布局**：画布宽高比按内容选——用户指定宽高/宽高比时直接采用；未指定时**优先匹配常用宽高比**（16:9、3:2 横版适合横向分层流程/架构图；2:3、9:16 竖版适合纵向长流程、时间线、步骤多的图），常用比例无法满足呈现与排列时才用**自适应比例和布局**。画布宽高必须是整数，背景 rect 用 100% 覆盖、与 viewBox 一致。自上而下分层：大容器包小块。每个元素都要精确坐标。布局与坐标直接参照 `references/sketch_recipe.md` 内嵌示例即可，**无需读取 `assets/` 下的示例 SVG 文件**。
3. **掷骰子（随机化）**：写代码前，先按 `references/sketch_recipe.md` 的「随机化」章节为本次生成确定全部随机参数——主题色板、纸张背景色、滤镜 seed 与 scale、排线角度/透明度、连接线颜色、涂鸦配置等。把选定的参数以注释形式写进 SVG 顶部（`<!-- 本次随机参数：… -->`），便于复核。
4. **生成 SVG**：按 `references/sketch_recipe.md` 的配方与本次已选随机参数写。文件结构固定为：
   - `<defs>`：两个抖动滤镜 `sketchA`/`sketchB`（**不同 seed**）、纸张点阵 pattern、各层排线 pattern、CSS `@import` 手写字体
   - 纸张背景 rect（米黄底 + 点阵）
   - **形状组** `<g filter="url(#sketchA)">`：所有矩形、小块、涂鸦装饰（**不含连接线**）
   - **边框模式（随机二选一，一图只用一种）**：抖动边框（直边 rect + 抖动滤镜 + 双描边叠线）或波浪边框（闭合波浪 path，副笔节点错相叠线 + 参数按容器独立随机，不加抖动滤镜）（二选一规则见 recipe 第 3 节，波浪细节见 3.2）
   - **描边组**（仅直边模式）`<g filter="url(#sketchB)">`：各大容器的第二遍描边（与第一遍错开形成"画了两笔"的叠线；用户要求单描边或波浪模式时删除本组及其滤镜定义，见 recipe 第 3.1.1 / 3.2 节）
   - **连接线组** `<g class="shapes">`：流程线/连接线/箭头/编号圆圈，**不使用任何滤镜**；弯折处用圆角过渡，禁止生硬直角
   - **文字组**（无滤镜）：所有文字
5. **校验 XML**：用 `python3 -c "import xml.etree.ElementTree as ET; ET.parse('文件')"` 确认合法。最常见坑：CSS `@import` 里的 `&` 必须写成 `&amp;`。
6. **渲染预览（仅用户要求 PNG 时执行）**：运行 `python3 <资源目录>/scripts/render_preview.py <svg>` 生成 PNG（资源目录按「路径说明」用 `resourceBase.path` 拼绝对路径，**不要硬编码具体路径**；cairosvg 缺失时脚本会自动建 venv 安装，首次较慢——默认不渲染、直接交付 SVG 更快，只有用户明确要预览图才执行）。
7. **交付**：默认只给 `.svg` 路径；仅当用户要求预览时才额外给出 `.png` 路径，并说明"预览图字体可能走回退字体，以浏览器打开 SVG 为准"。

## 关键规则

- **文字永远不进抖动滤镜**（会糊掉）；矩形/小块/涂鸦进滤镜；**流程线/连接线/箭头不进任何滤镜**（保持线条清晰），单独成组。
- 字体族：`'ZCOOL KuaiLe','Liu Jian Mao Cao','Kaiti SC','STKaiti','KaiTi','Comic Sans MS','Bradley Hand',cursive`。在线时浏览器自动加载快乐体/草书，离线回退楷体/Comic Sans。
- 默认**不做微旋转**；只有当用户明确要"更随意、歪歪扭扭"时才给大容器加 -1.5°~1.5° 的 rotate。
- **每次生成必须不同**（铁律）：同一需求重复生成两次，至少 3 个维度要可感知地不同——配色方案（A/B）、纸色、大块色组合、强调色、滤镜 seed/scale、排线角度、装饰布局等。手绘风的价值就在于"每一张都是独一份"。但随机必须"受控"：只从 recipe 随机化章节给出的候选池里选，保证风格始终协调，不出现突兀的颜色。
- 配色双方案二选一（掷色）：**A 沉稳纸感（≤8 色）**——1 纸色 + 2~4 中饱和大块色 + 1~2 高饱和强调色 + 墨色；**B 活泼鲜亮（≤10 色）**——1 纸色 + 2~4 明快鲜亮的大块色 + 1~2 亮强调色 + 墨色。纸色均为浅米/白灰/浅象牙纸张感；大块色按容器组分配、组间不撞色；文字与线条统一墨色；重点模块高饱和点睛。
- **大块取色跟着容器间的关系走**：递进/时间顺序 → 同一色族逐步加深（浅→深梯度，先后/升序一目了然）；并列/平行 → 同一色系；对立/对比 → 两个明显不同的色系（暖/冷拉开）。详见 recipe 8.3 / 8.7。
- **边框两种模式随机二选一（一图只用一种）**：**抖动边框**（直边 rect + 抖动滤镜 + 双描边叠线）或**波浪线边框**（闭合波浪 path，参数按容器独立掷：大容器 主段长 200~230/振幅±1 · 副段长 100~120/振幅±2；小模块 主段长 80~110/振幅±1 · 副段长 50~60/振幅±2；副笔节点错相 1/3~1/2 段长；不加滤镜；默认不断线），每次生成掷色二选一；用户明确要"波浪/抖线"或"整齐/直边"时按其意图选。同排并列大块小块参数不得完全相同（圆角除外）；一张图禁止混用两种模式。**具体参数范围一律以 recipe 第 3.2 节为准。**
- 连接线用轻微 S 形曲线 + 手绘箭头（不规则三角形，不要等腰标准三角形）；返回/辅助路径用虚线 `stroke-dasharray="7,6"`。
- **连接线不套滤镜**（单独成组，见工作流）；**弯折处一律圆角过渡（Q 曲线，半径 3~6px），禁止生硬直角**（T 形汇流可直连）。
- 连接线与边框的关系是铁律：分支线不得沿图形边框共线（走偏移通道 + 短横线 + 箭头接入）；线条起止点与边框留 3~5px 间隙或从块内垂直穿出；同一边框多组线垂直错开；外层容器边框不得与内部小图形边框重合（内部小块四周留边距），详见 recipe 第 7 节与避坑清单。
- 字号：大标题 26-30，层标题 15-16，块标题 12.5-13，说明 10-11.5；中英对照（中文主 + 英文副）提升专业感。
- **小块宽度随文本走**：块宽由内部文本长度决定（文本宽 + 左右各 10~14px 内边距），中文按 字号×字数、英文按 ≈0.55×字号×字符数 估算，以中英对照较长的一行为准；避免"文本短、图形长"的空白失衡，也别让文字贴边。同排并列的小块统一取组内最宽文本的宽度，整体更整齐。详见 recipe 第 9.1 节。
- **编号序列必须可区分（踩坑沉淀）**：**只在有递进/流程顺序语义时用编号**（并列/分组等无顺序关系不编号，用排版与层标题区分）；一张图里不同层级/含义的编号（主流程 / 返回辅助）要用不同圆圈样式并配图例。默认规则：序号统一用阿拉伯数字；主流程步骤=实心圆+白字；返回/辅助=灰色（配灰虚线）。不要用同一套样式标两套编号，也不要让编号圆圈/标注文字互相重叠（密集区域错位排布、缩短标注），详见 recipe 第 8.8 节。
- 可加少量涂鸦装饰（四角小星星、标题波浪下划线）增加手账感，但不要喧宾夺主。

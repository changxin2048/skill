# 手绘 SVG 完整配方（Sketch Recipe）

生成前必读。本文档自包含全部坐标、参数、色板与结构示例，**写代码前只需读本文件**，无需读取 `assets/` 下的示例 SVG（`eg.svg`/`eg2.svg` 仅供维护者人工核对，不是生成输入）。

---

## 0. 随机化总则（每次生成前必做）

手绘风的魅力在于"每一张都是独一份"。**每次生成都必须与之前的图不同**（同一需求重复两次，至少 3 个维度可感知地不同；配色几乎不可能重复）。

随机是**受控随机**：只从本文各章节的候选池/范围内取值，保证风格始终协调。配色遵循硬约束：**纸感背景 + 双方案二选一**——A **沉稳纸感**：中饱和大块色 + 高饱和强调色，全图 ≤8 色；B **活泼鲜亮**：明快鲜亮的大块色 + 亮色强调，全图 ≤10 色。两案共用"纸色/大块色/强调色/墨色"四角色框架，大块按容器组分配不杂乱，重点模块高饱和跳出来。

**掷骰子流程**（写代码之前完成）：
1. **掷方案**：A 沉稳纸感 / B 活泼鲜亮（约 50/50；用户语境偏"清爽/安静/素/沉稳"时选 A，偏"活泼/鲜亮/多彩/明快"时选 B）。
2. **掷纸色**：从纸色池选 1 个（见 8.4，两案共用，全部为浅米/白灰/浅象牙等纸张感颜色）。
3. **掷大块色**：按方案取池——A 从 8.1（中饱和）取 2~4 个，B 从 8.5（鲜亮）取 2~4 个；**先判容器间关系再取色**：递进/时间顺序 = 1 个色族做深浅梯度，并列 = 1 个色族同色，对立 = 2 个对比色族（暖/冷拉开），混合场景合计 2~4 个色族（见 8.3 / 8.7）。
4. **掷强调色**：按方案取池——A 从 8.2（高饱和）取 1~2 个，B 从 8.6（亮色）取 1~2 个；只用于重点模块、主流程箭头、主编号、小装饰。
5. **掷墨色**：随纸色场景取暖墨 `#3B3A36` 或冷墨 `#374151`，负责全部文字与线条。
6. **掷滤镜**：seed/scale/baseFrequency 随机（两个 seed 必须不同）。
7. **掷其余**：排线角度/透明度、虚线样式、装饰元素、**边框模式**（抖动 / 波浪**随机二选一**，约 50/50；用户语境偏"整齐/直边/正式"选抖动，偏"波浪/随性/抖线"选波浪；一图一种，见第 3 节）（见各节）。
8. 把全部已选参数写成 SVG 顶部注释：
   `<!-- 本次随机参数：方案=A 沉稳纸感；纸色=浅米 #F5F1E8；大块色=雾蓝 #C3D6DE/#5E8090 + 燕麦 #E8D9C0/#A1865F + 陶土 #E8C4AA/#B36F48；强调色=赭金 #D08A24 + 墨绿 #1F7A52；墨色=#3B3A36；seedA=31/scaleA=3.4；seedB=72/scaleB=4.0；排线=45°/0.14；装饰=星+螺旋；虚线="5,4" -->`

然后按这些参数写代码。自检：与上次生成的图对比，至少 3 个维度不同，且配色组合不同。

## 1. 文件骨架

### 1.1 画布宽高比选择（先常用比例，再自适应）

- 用户指定宽高或宽高比 → 直接采用，无需自选。
- 未指定时按图的形态**优先匹配常用宽高比**：
  - **16:9**（1600×900）/ **3:2**（1500×1000）：横向分层流程、架构图、左右分栏等"宽于高"的图。
  - **2:3**（1000×1500）/ **9:16**（900×1600）：纵向长流程、时间线、步骤多的"高于宽"的图。
  - **4:3**（1200×900）：结构较方正、模块均衡的图。
- 常用比例放不下（模块过多、布局极窄/极长等）才用**自适应比例与布局**：按内容反推宽高（整数），如 1100×960。
- 铁律：背景 rect 用 `width="100%" height="100%"` 覆盖全画布；`viewBox` 尺寸 = 全部坐标的范围；选定比例后**所有坐标按该画布重算**，禁止照搬其他尺寸示例的坐标。

```xml
<svg xmlns="http://www.w3.org/2000/svg" width="1600" height="900" viewBox="0 0 1600 900">
  <style>
    @import url('https://fonts.googleapis.com/css2?family=ZCOOL+KuaiLe&amp;family=Liu+Jian+Mao+Cao&amp;display=swap');
    .text { font-family: 'ZCOOL KuaiLe','Liu Jian Mao Cao','Kaiti SC','STKaiti','KaiTi','Comic Sans MS','Bradley Hand',cursive; }
    .shapes { stroke-linecap: round; stroke-linejoin: round; }
  </style>
  <!-- 本次随机参数：…（见第 0 节） -->
  <defs>…滤镜与 pattern…</defs>
  <!-- 纸张背景 -->
  <!-- 形状组：<g filter="url(#sketchA)" class="shapes">（矩形/小块/涂鸦装饰，不含连接线） -->
  <!-- 描边组：<g filter="url(#sketchB)" class="shapes">（大容器第二遍描边；单描边模式时整组删除） -->
  <!-- 连接线组：<g class="shapes">（流程线/连接线/箭头/编号圆圈，不使用任何滤镜） -->
  <!-- 文字组：<g class="text"> -->
</svg>
```

## 2. 抖动滤镜（两个，seed 每次不同）

```xml
<filter id="sketchA" x="-8%" y="-8%" width="116%" height="116%">
  <feTurbulence type="fractalNoise" baseFrequency="0.06" numOctaves="3" seed="7" result="n"/>
  <feDisplacementMap in="SourceGraphic" in2="n" scale="3.4" xChannelSelector="R" yChannelSelector="G"/>
</filter>
<filter id="sketchB" x="-8%" y="-8%" width="116%" height="116%">
  <feTurbulence type="fractalNoise" baseFrequency="0.055" numOctaves="3" seed="13" result="n"/>
  <feDisplacementMap in="SourceGraphic" in2="n" scale="4" xChannelSelector="R" yChannelSelector="G"/>
</filter>
```

**随机规则**（用户已验证偏好：位移幅度要小、噪声频率要高——滤镜只做轻微"手抖"，不做大幅扭曲）：
- `seed`：A 与 B 各取 1~199 内不同整数（每次都要换，这是抖动形态随机的关键）。
- `scale`：A 取 2.5~4.5，B 取 3~5.5（B 略大于 A）。**3 上下为佳**，超过 5 就太扭曲。
- `baseFrequency`：A 取 0.05~0.07，B 取 0.045~0.065。**0.055~0.06 为佳**，低于 0.04 则抖动呈大波浪、不像笔迹。
- 滤镜区域固定放大到 116%，防止边缘被裁。

## 3. 边框模式（抖动 / 波浪，随机二选一）

**边框模式二选一（掷色）**：**抖动边框**（3.1：直边 rect + 抖动滤镜 + 双描边叠线）与**波浪线边框**（3.2）每次生成随机选其一，约 50/50；用户明确要"波浪 / 随性 / 抖线"或"整齐 / 直边 / 正式"时按其意图选。**一张图只用一种边框模式**，禁止混用。

### 3.1 抖动边框（双描边叠线）

每个**大容器**画三层：
1. 填充 rect（sketchA 组）
2. 第一遍描边 rect，`stroke-width` 取 2.5~4（sketchA 组）
3. 第二遍描边 rect，`stroke-width` 取 1.3~2，颜色可同色相深一档（sketchB 组，seed 不同 → 与第一遍错开）

**内部小块**只画一遍描边（stroke-width 1.8~2.4），避免杂乱。圆角：容器 rx 8~18，小块 rx 5~12（每次在范围内随机取整）。

#### 3.1.1 单描边模式（用户要求"单描边 / 不要叠线"时）

默认双描边。若用户明确要求单描边：
1. 删掉整个**描边组**（sketchB 组里的全部第二遍描边 rect）；
2. 同时删掉 `<defs>` 里的 sketchB 滤镜定义（避免死代码）；
3. 只保留 sketchA 组内的主描边（大容器 2.5~4，小块 1.8~2.4）。

### 3.2 波浪线边框

**实现**：大容器/小块边框用**闭合波浪 path** 替代 `<rect>`：
- **填充跟随主波浪 path**：容器/小块的填充 rect 改用**主描边同一条波浪 path**（`fill="色值"`、无 stroke），保证填充贴合波浪边框，四角与波峰处不留白、不溢出。
- 四边各由 `Q` 曲线小段拼接：每段端点落在原矩形边上，控制点沿**垂直于边线**的方向偏移；四角用半径 r 的圆弧（`A` 命令）过渡，禁止生硬折角。
- **参数按容器独立掷（铁律）**：每个容器/小块单独掷出**全部随机参数**（段长、相位错相、渐变区间），**不同容器参数不重复（圆角除外）**——同排并列的小块边框绝不能一模一样。
  - **主描边（第一遍，线宽线性渐变）**：
    - **大容器**：段长 200~230px（随机）、振幅 ±1、圆角 r 12~16；线宽沿周长**线性渐变**（渐变区间每容器掷：起点 0.1~0.3、终点 1.8~2.2）——三角波线性插值 `w = (tri(t)+1)/2·(wmax−wmin)+wmin`（t 为沿周长归一化位置，周期 k 取 1~2）。
    - **内部小块**：段长 80~110px（随机）、振幅 ±1、圆角 r 6~10、渐变起点 0.1~0.25 / 终点 1.0~1.3、周期 k 1~2（每块独立掷）。
  - **副描边（第二遍，双描边叠线）**：用**节点错相**重生成一遍同轮廓——Q 分段节点（knots）沿边相对主描边偏移 **1/3~1/2 个段长**（每容器独立随机），波峰/波谷交错、两遍必然分开；统一细线（大容器 0.7~1.1、小块 0.4~0.8，每容器独立掷），颜色取同色相深一档（如 `#4A6877`），叠加在主描边上，形成"画了两笔"的叠线；副描边段长**与主描边独立掷**（大容器 100~120px、小块 50~60px）。
- **不加抖动滤镜**（波浪 + 双遍叠线已足够手绘感，再叠滤镜会双层抖），本模式下不创建 sketchB 滤镜与描边组。**默认不断线**；若用户要求"断墨"效果：只在大容器最细线宽段断 1 段、断后 1 段细虚线（`dasharray "4,7"`）恢复，断线段数 ≤ 总段数的 8% 且总段数 ≥ 12 才断。
- 示例（大容器顶边两遍 + 圆角过渡，坐标仅为示意）：
```xml
<!-- 波浪模式·主描边（示意参数：段长220 / ±1 / 圆角r14；实际按容器独立随机） -->
<path d="M104,170 Q214,169 324,170 Q434,171 544,170 Q654,169 764,170 A14,14 0 0 1 778,184 ... Z"
      fill="none" stroke="#5E8090" stroke-width="1.4"/>
<!-- 副描边：节点错相 1/3~1/2 段长、段长独立掷（≈110）、统一细线叠加 -->
<path d="M104,170 Q181,172 258,170 Q335,169 412,170 ..." fill="none" stroke="#4A6877" stroke-width="0.9"/>
```
- 波浪模式下，排线、配色（8.3 / 8.7）、文字、连接线等其余规则不变。

## 4. 纸张背景（色池 + 点阵随机）

纸色从纸色池随机（见 8.4）——**只允许浅米/白灰/浅象牙等纸张感颜色**。点阵色 = 纸色同族深一档（如 `#D6D1C4` 一类），opacity 0.35~0.5，让背景保持"纸"的素净，不得发花。

```xml
<pattern id="paperDots" width="22" height="22" patternUnits="userSpaceOnUse">
  <circle cx="3" cy="3" r="1.3" fill="#cbbfa9" opacity="0.5"/>
</pattern>
<rect width="100%" height="100%" fill="<!-- 选定的纸色 -->"/>
<rect width="100%" height="100%" fill="url(#paperDots)"/>
```

**点阵随机**：`width/height` 取 16~28，`r` 取 1.0~1.6，`opacity` 取 0.35~0.65。

## 5. 铅笔排线（叠加在大容器填充之上）

```xml
<pattern id="hatch" width="8" height="8" patternUnits="userSpaceOnUse" patternTransform="rotate(45)">
  <line x1="0" y1="0" x2="0" y2="8" stroke="#A1865F" stroke-width="1" opacity="0.14"/>
</pattern>
```

**随机规则**：`rotate` 取 15/30/45/60/75 之一；`stroke-width` 取 0.8~1.3。每个容器一个 pattern，`stroke` 用所在容器**大块色描边档**（方案 A 用 8.1 中饱和池、方案 B 用 8.5 鲜亮池）；`opacity`：方案 A 取 0.08~0.18，方案 B 取 0.10~0.20。用法：`<rect … fill="url(#hatch)"/>` 叠在填充 rect 之后。

## 6. 手绘箭头（不用 marker，直接画不规则三角形）

```xml
<!-- 向下箭头 -->
<path d="M543,232 L557,234 L550,244 Z" fill="#D08A24"/>
<!-- 向上箭头 -->
<path d="M193,551 L207,553 L200,542 Z"/>
```

**随机规则**：底边两端点高度差 1~3px、顶点偏离中线 1~2px（随手感），具体偏移量每次不同。不要画等腰标准三角形。箭头颜色 = 第 7 节箭头主色规则。**箭头与流程线/连接线同组，不套任何滤镜**（见第 7 节）。

## 7. 连接线

- **流程线/连接线/箭头不使用任何滤镜**（用户已验证偏好）：单独一组 `<g class="shapes">`，置于所有滤镜组之外。滤镜只作用于矩形与涂鸦，线条保持清晰利落。
- 主连接用轻微 S 形三次曲线：`M550,198 C547,208 553,222 550,233`（中点偏移 3~6px，每次不同）。
- 返回/辅助路径用虚线，`stroke-dasharray` 在 `"7,6"`/`"6,5"`/`"8,6"`/`"5,4"` 中随机，颜色 = 墨色 50% 透明度。
- 分支线：先垂直一小段 → 水平段 → 垂直进目标。
- **弯折处一律圆角过渡，禁止生硬直角**（用户已验证偏好）：所有 L 形 90° 转弯用 Q 曲线（半径 3~6px）；T 形汇入点（横线接竖线汇流）可直连。例：
```xml
<!-- 生硬直角（不要） -->
<path d="M300,300 L300,352 L352,352"/>
<!-- 圆角弯折（要）：Q 曲线，半径约 4px -->
<path d="M300,300 L300,348 Q300,352 304,352 L352,352"/>
```

### 连接线与边框的关系（铁律，踩坑沉淀）

1. **分支线绝不能沿图形边框走**。竖线贴着块左边框上下延伸 = 线条与边框共线重合，视觉上像画错了。正确做法：分支竖线走**偏移通道**（例：块左边框在 x:750，竖线走 x:730），到目标高度后接**短横线**，箭头在边框处接入块内。
2. **线条起止点不要恰好落在边框上**。无箭头的一端离边框留 3~5px 间隙；有箭头的一端让箭头尖端落在边框上、线体停在箭头之后。也可让线从块**内部**引出、垂直穿过边框。
3. **同一侧边框的多组线要在垂直方向错开**。如"调用进入"与"结果返回"都接在块的左边缘：进入点取 y:258/438/618、返回点取 y:290/470/650——两套线永无共线段。
4. 垂直交叉（实线×虚线）可接受且正常；**共线/重合**不可接受。画完自查：任意线条与任意边框不得有超过一个点的接触。

**箭头主色规则（不设独立箭头色池，避免超色）**：
- 主流程箭头 = 本次掷出的**强调色**（方案 A 见 8.2，方案 B 见 8.6）。
- 辅助/返回箭头与虚线 = **墨色 45%~55% 透明度**。

## 8. 色板（双方案：A 沉稳纸感 ≤8 色 / B 活泼鲜亮 ≤10 色）

**方案 A（沉稳纸感，≤8 色）**：纸色 1 + 中饱和大块色 2~4（8.1）+ 高饱和强调色 1~2（8.2）+ 墨色 1。适合架构图、系统图等正式沉稳的表达。
**方案 B（活泼鲜亮，≤10 色）**：纸色 1 + 明快鲜亮大块色 2~4（8.5）+ 亮色强调 1~2（8.6）+ 墨色 1。适合演示、教学、运营活动等需要抓眼球的场景。

四角色分工（两案通用）：

| 角色 | 用途 | 说明 |
|---|---|---|
| 纸色 | 画布背景 + 小块填充 | 极浅、纸张感（8.4，两案共用） |
| 大块色（2~4 种） | 普通大容器填充/描边、小块描边、排线 | 按方案取池：A 中饱和（8.1）/ B 鲜亮（8.5） |
| 强调色（1~2 种） | 重点模块、主流程箭头、主编号、装饰 | 按方案取池：A 高饱和（8.2）/ B 亮色（8.6） |
| 墨色 | 全部文字、连接线、辅助编号、虚线 | 近黑中性 |

### 8.3 分配规则·方案 A（全图 ≤8 色）

- 方案 A 掷色顺序：纸色（8.4）→ 大块色 2~4 个（8.1）→ 强调色 1~2 个（8.2）→ 墨色（暖纸 `#3B3A36` / 冷纸 `#374151`）。
- **普通大容器**：大块色填充（浅档）+ 同色描边（深档）+ 同色排线。**先判容器间关系，再决定取色**（一个色族 = 8.1 表中一行，含 填充/描边 两档）：

  - **对立 / 对比**（正反对照、双方案、内/外流）：取**两个色相明显不同**的大块色（暖 vs 冷，或互补方向），分给对立双方。

- **重点模块（每张图限 1~2 处）**：描边用强调色全彩，填充用强调色浅档；若做"实心"重点块（如核心引擎），填充用强调色全彩 + 白字。除重点模块外，**任何地方不得出现强调色大面积填充**。

- **文字**：大标题/块标题/说明统一墨色（说明可降 70% 透明度）；层标题用所在容器大块色深档；重点模块实心底内的文字用白色/纸色。
- **连接线/箭头**：主流程箭头 = 强调色；辅助/返回路径 = 墨色 45%~55% 透明度（见第 7 节）。

### 8.8 编号样式区分（必做，踩坑沉淀）

一张图里若存在**不同层级或不同含义的编号序列**，样式必须可感知地区分，否则读者分不清哪个是主流程、哪个是内部步骤。

**默认规则（用户已验证偏好）**：
- **只在有顺序语义时用编号**：编号表达**递进 / 流程顺序**（步骤 1→2→3、时间线、执行顺序）。**无递进关系或无流程顺序关系**（并列模块、同级分组、纯结构展示）**不使用编号**——并列靠排版 / 同色 / 层标题区分，硬加编号会把并列误读成先后顺序。
- 序号统一用**阿拉伯数字**（1、2、3…），不用圈号 ①②③（部分字体/预览工具下圈号字形不稳定）。
- **主流程步骤**：实心圆 + 白字（fill = 强调色，stroke 用强调色深一档）。如 `1 用户请求 → 2 推理请求 → …`
- **循环/内部流程步骤**：少于等于3个时不使用编号，多余3个使用空心圆+编号（空心圆用墨色描边）。
- **返回/辅助路径**：墨色 40% 灰实心圆（+ 白字，或空心墨色圈）+ 墨色半透明虚线连接，标注文字用墨色降透明度。
- 不同序列的数字可以重复（主流程 1-5 与内部 1/2/3 共存），靠**实心/空心/颜色**区分；若仍易混，可把次要序列换成中文/罗马数字，但默认优先阿拉伯数字 + 样式区分。
- 编号圆圈旁紧跟简短标注文字（如 `1 用户请求`），颜色与圆圈语义一致；分支处行内标签（如 `调用工具`）可不带编号，避免与主编号文字重复。

**避免重叠（踩坑沉淀）**：
- 多个编号集中在同一区域时（如流程线密集区），先算好每个圆圈 + 标注文字的包围范围再落位：圆圈错开 y、文字缩短、必要时调整 text-anchor（如返回线编号文字右对齐到竖线左侧）。
- 编号圆圈不得压在连接线/虚线/容器边框上（r=11 的圆圈至少留 5px 间隙）。
- 实心圆内的数字必须用白字，空心圆内的数字必须用深色字（同色相深档），保证对比度。

示例 XML（实心主流程 +灰色辅助）：
```xml

<circle cx="556" cy="206" r="11" fill="#1F7A52" stroke="#1A6444" stroke-width="1.6"/>
<text x="556" y="210" text-anchor="middle" font-size="12" font-weight="700" fill="#ffffff">1</text>

<!-- 返回/辅助：墨色 40% 灰实心圈 -->
<circle cx="820" cy="552" r="11" fill="#3B3A36" fill-opacity="0.4" stroke="#3B3A36" stroke-width="1.6"/>
```

### 9.1 小块宽度随文本走（避免"文本短、图形长"）

块宽由内部文本决定：**先估算文本宽，再加内边距**。

- **估算**：中文按 字数 × 字号（汉字近方形，如 12.5px 字号 × 6 字 ≈ 75px）；英文/数字按 ≈0.55~0.6 × 字号 × 字符数；中英对照以**较长的一行**为准（英文 `<tspan>` 降档后按降档字号算）。
- **内边距**：左右各 10~14px，上下各 8~12px；文本不足 2 字时用最小块宽 60~70px 兜底。
- **宽度上限**：单行文本的块宽 ≤ 约 180px；超长文本分两行（换行）或放宽块宽，不要撑到与容器齐宽。
- **并列对齐**：同一排并列的小块统一取**组内最宽文本**的宽度对齐；不同排可自由宽度，但同一行内必须一致。
- **自查**：任何小块的文本两侧空白各 ≥ 10px，禁止出现"文本 2 个字、块宽 200px"的失衡；同一容器内并列块宽度差不超过 20px。

## 11. 避坑清单（每条都是踩过的坑）

1. **CSS `@import` 里的 `&` 必须写成 `&amp;`**，否则 XML 解析报 `not well-formed (invalid token)`。
2. **文字绝不能进滤镜组**——会糊成一团。形状组和文字组必须分离。
3. 滤镜区域必须扩大（`x="-8%" y="-8%" width="116%" height="116%"`），否则边缘被裁。
4. 双描边必须用**不同 seed** 的两个滤镜，否则两遍描边完全重合等于没画。
5. SVG 无自动排版，每个元素都要显式坐标；先算好布局再写代码。
6. 文件保存为 UTF-8，中文直接书写，无需转义。
7. 生成后**必须**用 XML 解析校验（见下），再交付。
8. **外层容器边框不能与内部小图形边框重合**：内部小块四周必须留边距——底边至少 8~14px、左右至少 10~14px、顶部位于层标题之下；等距排布 N 个小块时先算好坐标，让最后一块的底边明显高于容器底边框（例：块高 160 内放 3 条，条高 32 + 间距 8 + 底部留 14）。连接线尽量穿过小块之间的缝隙。
9. **连接线不得沿边框共线**：分支竖线贴块边 = 重合，必须走偏移通道 + 短横线 + 箭头接入；线体起止点留 3~5px 间隙或从块内垂直穿出；同一边框多组线垂直错开（详见第 7 节"连接线与边框的关系"）。
10. **单描边模式**：用户要求单描边时，删除整个 sketchB 描边组与 sketchB 滤镜定义，只留 sketchA 主描边（详见第 3.1.1 节）。
11. **连接线不套滤镜**：流程线/连接线/箭头/编号圆圈单独成组，置于所有滤镜组之外（滤镜只作用于矩形与涂鸦）；套了滤镜的线条会随图形一起抖，违背"线条清晰"的要求。画完自查：连接线组内不应出现 `filter=` 属性。
12. **弯折处不用生硬直角**：所有 L 形 90° 转弯用 Q 曲线圆角过渡（半径 3~6px）；T 形汇入点可直连。逐条检查路径里的 `L` 拐角，有直角就换成 `Q`。
13. **小块宽度必须随文本定**：先算文本宽再加左右 padding（10~14px），禁止"文本短、图形长"（如 2 个字塞进 200px 宽块）。同排并列块统一取组内最宽文本的宽度，同一行内宽度一致；单行块宽上限约 180px，超长文本分行。详见第 9.1 节。
14. **画布比例与背景必须一致**：选定宽高比后，背景 rect 用 `width="100%" height="100%"`；`viewBox` 与全部坐标必须按所选画布重算，禁止沿用旧示例的 1100×960 坐标（见 1.1）。
15. **边框模式一图只选一种**：波浪模式（3.2）与抖动边框（3.1）禁止混用；波浪模式下不加抖动滤镜（叠线由**两遍节点错相（1/3~1/2 段长）**的波浪 path 实现）、四角必须用圆弧（`A`）过渡；断墨（若启用）只断最细 1 段、断后细虚线恢复，断线段数 ≤8% 总段数。
